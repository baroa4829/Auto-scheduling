# Auto-scheduling — 구글 앱스 스크립트 버전 (서버 없음)

PC나 서버 없이 **구글 계정만으로** 동작하는 버전입니다.
안드로이드 폰의 MacroDroid가 카카오톡·당근 알림을 구글 앱스 스크립트로 보냅니다.
앱스 스크립트는 Claude로 약속을 찾아 내 구글 캘린더에 바로 등록합니다.

```
카톡/당근 알림 → MacroDroid → 구글 앱스 스크립트 (구글 클라우드, 무료)
                                 ├ 스크립트 저장 공간에 최근 대화·일정·토큰 사용량 저장
                                 ├ Claude로 약속 추출 (생성/수정/취소, 확정/미정)
                                 └ 구글 캘린더에 등록
```

- 휴대폰에서 하는 일은 알림이 올 때 작은 요청을 하나 보내는 것뿐이라 **배터리 소모가 거의 없습니다.**
- 앱스 스크립트는 무료입니다. 비용은 Claude API 사용료만 듭니다.
- 대화 기록은 최근 48시간 것만 보관하고, 그보다 오래된 것은 자동으로 지웁니다. 구글 드라이브에 파일을 만들지 않습니다.

준비물: 구글 계정, Claude API 키, 안드로이드 폰

---

## 1단계: Claude API 키 발급

1. https://console.anthropic.com 에 로그인합니다.
2. 결제 수단을 등록합니다.
3. **API Keys**에서 키를 만들고 `sk-ant-...` 값을 복사해 둡니다.

## 2단계: 앱스 스크립트 프로젝트 만들기

1. PC 브라우저에서 https://script.google.com 을 열고 **새 프로젝트**를 누릅니다.
2. 왼쪽 위의 "제목 없는 프로젝트"를 눌러 이름을 `Auto-scheduling`으로 바꿉니다.
3. 편집기의 `Code.gs` 내용을 모두 지웁니다. 이 폴더의 [`Code.gs`](Code.gs) 내용을 **전부 복사해 붙여넣고** 저장(💾)합니다.
4. 왼쪽 ⚙️ **프로젝트 설정**에서 두 가지를 합니다.
   - **시간대**를 `(GMT+09:00) 서울`로 바꿉니다.
   - 아래쪽 **스크립트 속성 → 스크립트 속성 추가**를 누르고, 속성은 `ANTHROPIC_API_KEY`, 값은 1단계에서 복사한 키를 넣은 뒤 저장합니다.

## 3단계: 최초 설정 실행

1. 왼쪽 `< >` **편집기**로 돌아가 위쪽 함수 선택 상자에서 `setup`을 고르고 **▶ 실행**을 누릅니다.
2. 권한 요청 창이 뜹니다.
   1. **권한 검토**를 누르고 내 계정을 선택합니다.
   2. "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → Auto-scheduling(으)로 이동(안전하지 않음)**을 누릅니다. 내가 만든 스크립트라 이런 경고가 나오는 것입니다.
   3. 캘린더, 외부 서비스 연결 권한을 **허용**합니다. 체크박스가 있으면 **모두 선택**하세요.
3. 아래 **실행 로그**에 다음 내용이 나옵니다.
   - `일정을 넣을 캘린더: ...` → 일정이 등록될 캘린더 이름입니다.
   - `웹훅 토큰: xxxxxxxx...` → **이 값을 복사해 두세요.** MacroDroid 설정에 씁니다.
4. (선택) 함수 상자에서 `tryExample`을 고르고 실행합니다. 예시 대화("내일 저녁 7시에 강남역에서 볼래?" → "좋아!")에서 Claude가 찾아낸 일정이 로그에 나오면 Claude 연결은 성공입니다. 캘린더에는 쓰지 않습니다.

## 4단계: 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. ⚙️(유형 선택)에서 **웹 앱**을 고릅니다.
3. 다음과 같이 설정합니다.
   - 설명: `v1`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누르고 나온 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
5. 휴대폰 브라우저에서 그 URL을 열어 `{"ok":true,...}`가 보이면 준비가 끝난 것입니다.

> "모든 사용자"로 해야 MacroDroid가 로그인 없이 접속할 수 있습니다. 대신 **웹훅 토큰이 없는 요청은 모두 거부**합니다. 토큰은 다른 사람에게 알려주지 마세요.

> ⚠️ **나중에 코드를 고치면** 다시 배포해야 반영됩니다. **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포** 순서로 하면 URL이 그대로 유지됩니다.

## 5단계: 휴대폰(MacroDroid) 설정

1. **알림 미리보기를 켭니다.**
   - 카카오톡: 설정 → 알림 → **메시지 알림 미리보기** 켜기
   - 당근: 채팅 알림 켜기
2. Play 스토어에서 **MacroDroid**를 설치합니다.
   - 알림 접근 권한을 허용합니다.
   - 휴대폰 설정 → 애플리케이션 → MacroDroid → 배터리에서 **제한 없음(최적화 제외)**으로 바꿉니다.
3. **매크로 추가**
   - **트리거:** `알림 수신`(알림 → 알림 수신)을 고르고, 앱은 **카카오톡**과 **당근**을 선택합니다. 텍스트 조건은 "모두"로 둡니다.
   - **액션:** `HTTP 요청`(웹 상호작용 → HTTP 요청)
     - 요청 방식: **POST**
     - URL: 4단계에서 복사한 **웹 앱 URL**
     - **쿼리 파라미터**를 추가합니다. 값 칸 옆의 `…`(매직 텍스트) 버튼에서 항목을 고르면 됩니다.

       | 이름 | 값 |
       |---|---|
       | `token` | 3단계의 웹훅 토큰 (직접 입력) |
       | `app` | 매직 텍스트 → **앱 이름** (또는 패키지 이름) |
       | `title` | 매직 텍스트 → **알림 제목** |
       | `text` | 매직 텍스트 → **알림 텍스트** |

     - 리디렉션 따르기 옵션이 있으면 켭니다. 구글 웹 앱은 응답을 다른 주소로 넘겨서 돌려주기 때문입니다. 이 옵션이 꺼져 있어도 일정 등록은 정상적으로 됩니다.
4. 매크로를 저장하고 켭니다.

## 6단계: 테스트

1. 친구에게 **"내일 저녁 7시 강남역 어때?"**를 보내 달라고 하고 **"좋아"**라고 답합니다.
2. 구글 캘린더에 일정이 생겼는지 확인합니다.
3. 안 되면 아래를 확인합니다.
   - 앱스 스크립트 왼쪽 **☰ 실행** 메뉴에서 `doPost` 실행 기록과 로그를 봅니다. `알림 수신: 앱=... 방=... 내용=...` 줄이 있는지 확인하세요.
   - 기록이 전혀 없다면 MacroDroid에서 요청이 오지 않은 것입니다. 매크로 로그(MacroDroid → 시스템 로그)를 확인하세요.
   - `invalid token`이 나오면 토큰 값이 틀린 것입니다.

처음에는 캘린더에 쓰지 않고 시험만 해 보고 싶다면, `Code.gs` 맨 위 `CONFIG`의 `DRY_RUN: true`로 바꾸고 다시 배포하세요.

## 사용하면서

- **토큰 사용량 확인**
  - 브라우저에서 `웹앱URL?action=usage&token=웹훅토큰`을 열면 오늘, 이번 달, 전체 합계가 나옵니다.
  - 편집기에서 `showUsage` 함수를 실행해도 됩니다.
  - 비용은 추정치입니다. 정확한 청구액은 console.anthropic.com 에서 확인하세요.
- **등록된 일정 보기:** 구글 캘린더에서 보면 됩니다. 일정 설명란에는 근거가 된 메시지가 적혀 있습니다. 편집기에서 `showEvents`를 실행하면 스크립트가 기억하는 일정 목록도 볼 수 있습니다.
- **설정 바꾸기:** `Code.gs` 맨 위 `CONFIG`를 고치고 다시 배포합니다.

  | 항목 | 기본값 | 설명 |
  |---|---|---|
  | `CALENDAR_ID` | `''`(기본 캘린더) | 구글 캘린더에서 "채팅 약속" 같은 캘린더를 따로 만들고, 설정 → 캘린더 통합 → 캘린더 ID를 넣으면 깔끔하게 구분됩니다 |
  | `INCLUDE_TENTATIVE` | `false` | `true`면 상대가 아직 답하지 않은 약속도 `[미정]`을 붙여 등록합니다 |
  | `DRY_RUN` | `false` | `true`면 캘린더에 쓰지 않습니다 |
  | `EFFORT` | `low` | Claude의 추론 강도입니다. 날짜를 자주 틀리면 `medium`으로 올리세요. 대신 비용과 시간이 늘어납니다 |
  | `CONTEXT_HOURS` | `48` | 대화 기록을 보관하는 시간입니다. 약속을 이해하는 데 쓰는 최근 대화의 범위이기도 합니다 |

## 알아둘 점

- 알림이 뜬 메시지만 읽을 수 있습니다. 그 채팅방을 열어 보고 있는 중이라 알림이 뜨지 않은 메시지는 읽지 못합니다.
- 단톡방은 MacroDroid가 방 이름을 따로 주지 않으면 보낸 사람별로 대화가 나뉩니다. 그러면 약속을 덜 정확하게 알아볼 수 있습니다.
  알림 서브텍스트(대화방 이름)를 고를 수 있다면 `room` 파라미터로 추가하세요.
- 채팅 내용은 일정 추출을 위해 Claude API(Anthropic)로 전송됩니다. 약속과 관련 없어 보이는 메시지("ㅋㅋㅋ" 등)는 보내지 않습니다.
  단, 직전에 약속 이야기가 있었거나 미확정 약속이 남아 있으면 "좋아" 같은 짧은 답장도 함께 보냅니다.
- 앱스 스크립트에는 하루 사용 한도가 있습니다(외부 요청 수, 실행 시간). 개인이 쓰는 양에는 충분합니다.
